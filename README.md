# 图透镜 Image Lens

图透镜 Image Lens 是一个 Chrome 浏览器插件，用于分析网页图片，并将图片内容反推为可编辑、可复制、可用于生图的提示词。
<img width="484" height="939" alt="PixPin_2026-05-08_22-58-28" src="https://github.com/user-attachments/assets/10572065-cb31-46d7-b7f4-8ed194f76978" />

当前版本基于 Gemini API 实现图片识别与生图能力。插件采用自备 API Key 模式：项目不会内置、提供或托管任何 API Key，用户需要在插件选项页填写自己的 API Key 后使用。

## 功能特性

- 在网页图片左上角显示快捷识别按钮
- 点击图片按钮后自动分析图片内容
- 生成精简版 / 完整版提示词
- 支持中文 / 英文提示词切换
- 支持结构化查看提示词内容
- 支持直接编辑识别出来的提示词
- 支持一键复制提示词
- 支持在弹窗内直接生图
- 支持选择生图比例：1:1、3:4、4:3、9:16、16:9
- 支持在新页面查看和下载生成图片
- 深色液态玻璃风格界面

## 当前默认模型

当前版本默认使用 Gemini：

- 图片识别模型：`gemini-3.1-pro-preview`
- 图片生成模型：`gemini-3.1-flash-image-preview`

不同账号、地区、套餐或 API 版本可能支持不同模型。如果遇到模型不可用，请到插件选项页修改模型名称，或参考 Gemini 官方文档确认当前可用模型。

## 安装方式

### 从源码安装

1. 下载或克隆本项目到本地。
2. 打开 Chrome，进入 `chrome://extensions/`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择本项目所在文件夹。
6. 安装完成后，进入插件选项页填写 API Key。

## 使用方式

1. 打开插件选项页。
2. 填写「识别图片模型 API Key」。
3. 如需使用生图功能，开启「生图功能」，并填写「生图模型 API Key」。
4. 如果识别和生图都使用 Gemini，同一个 API Key 可以填写到两个位置。
5. 打开任意包含图片的网页。
6. 鼠标移动到图片上，图片左上角会出现插件按钮。
7. 点击按钮后，插件会分析图片并生成提示词。
8. 你可以切换精简版 / 完整版、中文 / 英文、查看结构、手动编辑，或一键复制。
9. 如已开启生图功能，可以选择比例并点击「立刻生图」。

## API Key 与隐私说明

本项目采用自备 API Key 模式。

- 插件不会内置作者的 API Key。
- 插件不会向项目作者或第三方服务器上传你的 API Key。
- API Key 会保存在当前浏览器的 `chrome.storage.local` 中。
- 图片识别和生图请求会直接发送到用户配置的 Gemini API。
- 当你点击识别图片时，插件会读取目标图片，并将图片数据发送给 Gemini API 用于分析。
- 当你点击生图时，插件会将当前提示词发送给 Gemini API 用于生成图片。
- 项目作者不会收集、存储或分析你的网页内容、图片内容、提示词或生成结果。

请注意：只要 API Key 填写在浏览器插件中，它就属于客户端持有。请妥善管理自己的 API Key，并根据需要在 API 平台设置额度、权限和风控规则。

更完整的说明见 [PRIVACY.md](./PRIVACY.md)。

## Chrome 权限说明

本插件需要以下权限：

- `storage`：用于在本地保存用户填写的 API Key、模型名称和插件设置。
- `tabs`：用于打开插件选项页或结果查看页。
- `<all_urls>`：用于在网页图片上注入识别按钮，并读取用户点击的网页图片。

插件只会在用户主动点击图片识别按钮后发起图片分析请求。

## 常见问题

### 为什么填了 API Key 还是不能用？

可能原因包括：

- API Key 无效或没有启用 Gemini API。
- 当前账号没有对应模型权限。
- 模型名称填写错误。
- 当前地区或套餐暂不支持该模型。
- 图片跨域、失效或无法被插件读取。

### 为什么生图模型报 not found？

这通常表示当前 API 版本、账号、地区或套餐不支持该模型。请到 Gemini 官方文档查看当前可用模型，并在插件选项页修改模型名称。

### 插件会不会上传我的 API Key？

不会。API Key 只保存在本地浏览器的 `chrome.storage.local`。项目作者没有服务器，也不会接收你的 API Key。

### 能否支持其他模型厂商？

当前版本主要围绕 Gemini API 实现，暂不内置其他模型厂商的适配。

如果你希望接入其他模型厂商，可以基于本项目代码自行修改和适配。通常需要调整的部分包括：

- `background.js` 中的 API 请求地址、鉴权方式和请求参数
- 图片识别接口的输入格式与返回解析逻辑
- 生图接口的输入格式、比例参数和图片结果解析逻辑
- `options.html` / `options.js` 中的模型配置项

不同厂商在识图、生图、模型命名、鉴权方式、额度套餐和返回结构上差异较大，因此本项目不保证其他厂商可以直接替换模型名称后使用。
