# 禅击木鱼

一个纯前端的任天堂禅意像素风格敲木鱼小游戏原型。

## 已实现

- `3, 2, 1` 倒数后开始 60 秒节拍局
- 固定频率引导音 + 玩家点击判定
- 基于误差毫秒的得分、连击和扣分
- 难度选择
- 本地排行榜
- 本地成就
- 分享文案
- 夜间禅境彩蛋

## 运行

直接在浏览器打开 `/Users/kevinchin/Documents/Playground/index.html` 即可。

如果浏览器限制本地文件音频上下文，使用任意静态服务器启动当前目录即可。
